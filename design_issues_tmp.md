# Design issues of the Roc platform for Cloudflare Workers: state at HEAD

This file lists the UX and design issues that probes found in the platform at the old commit 703a519 (2026-10-17, nightly-2026-10-12). The probes and findings are in `research/plugin-probes/` (FINDINGS-core.md, FINDINGS-do.md, FINDINGS-storage.md). This check is from 2026-10-26. It compares each issue with the HEAD sources (`platform/*.roc`, `MODULES.md`, `API.md`, `PLAN.md`). No probe ran and nothing was built. The check is by reading only. Step 8h ("Status of step 8h", `PLAN.md:2816`) and the later work (G1a, typed DO namespaces, interface names) fixed most issues. Rows 1 to 10 are the old issues (issue 2 has 7 sub-rows, 2a to 2g). Rows X1 to X10 are findings that were not in the list. Where code and docs disagree, the row says so. The old list says 11 issues, but it had 10 numbered items.

Result: 11 Fixed, 8 Partly fixed, 7 Open.
